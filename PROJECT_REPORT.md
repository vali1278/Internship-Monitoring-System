# Internship Monitoring System

## Department
Artificial Intelligence and Machine Learning (AIML)

## Project Objective
To monitor and manage student internship activities through a web-based platform.

## Modules

### Student Module
- Login
- Registration
- Daily Report Submission
- Photo Upload

### Faculty Module
- View Student Reports
- Monitor Internship Progress

### Admin Module
- Manage Students
- Manage Faculty
- Generate Reports

## Technologies Used
- Python Flask
- HTML
- CSS
- MySQL
- GitHub

## Future Enhancements
- AI-based Performance Analysis
- Email Notifications
- Automated Report Generation

## Conclusion
The Internship Monitoring System simplifies internship tracking and monitoring for students, faculty, and administrators.
